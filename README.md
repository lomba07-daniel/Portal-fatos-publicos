# Portal Fatos Públicos

Nome provisório e neutro do projeto.

Portal experimental baseado prioritariamente em fatos verificáveis: votos, emendas, gastos de mandato, despesas/receitas eleitorais, projetos, patrimônio e trajetória.

## Publicação
A estrutura foi preparada para GitHub Pages: `index.html` fica na raiz.

## Segurança
Antes desta cópia ser preparada, o pacote foi revisado para procurar:
- tokens/chaves/senhas;
- e-mails;
- caminhos locais;
- arquivos de credenciais;
- CPF/CNPJ.

Nenhum segredo ou identificação do responsável pelo projeto foi encontrado. CNPJs públicos presentes nos dados eleitorais foram removidos por minimização.

Consulte `DADOS_E_PRIVACIDADE.md`.
